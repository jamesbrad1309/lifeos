# Languages: English and Vietnamese

The web app speaks **English** and **Vietnamese** (`tiếng Việt`). The
**EN | VI** switch in the app bar changes the whole app and is remembered.
The first visit uses the browser's preferred language.

## How it's put together

| Piece | Where | What it does |
| ----- | ----- | ------------ |
| Setup | `src/i18n/i18n.ts` | i18next + react-i18next; picks the language (saved in `localStorage` → browser language → English), keeps `<html lang>` in step |
| Dictionaries | `src/i18n/en/*.ts`, `src/i18n/vi/*.ts` | One file per area: `common`, `shell`, `habits`, `journal`, `finance` |
| Types | `src/i18n/types.d.ts` | `t("…")` keys are checked against the English dictionary |
| Formatting locale | `src/i18n/locale.ts` | `en-GB` / `vi-VN`, used by `lib/money.ts` and `lib/dates.ts` |

- **English is the source.** Each Vietnamese file is typed `typeof en`, so a
  missing, extra or misspelled key in Vietnamese is a compile error.
- **Switching re-renders everything.** The root route keys `AppShell` by
  language, so numbers and dates formatted outside `t()` update too.
- **Page titles** come from `staticData: { page: "journal" }` on each route,
  looked up in `shell.pages`.

## Adding a string

1. Add the key to the English file for that area, then the same key to the
   Vietnamese file (TypeScript tells you if you forget).
2. `const { t } = useTranslation();` then `t("area.key", { name })`.
   Use `<Trans i18nKey components={{ b: <b /> }} />` when the text has markup.
3. Plurals: `key_one` / `key_other` with `{ count }`. Vietnamese has no
   plural forms, so both are the same there.

## Adding a language

Add it to `LANGUAGES` in `i18n.ts` (label, short code, Intl locale), create
`src/i18n/<code>/` with every file typed against English, and register it in
the `resources`. For the journal, also add it to `WORDS` in
`lib/journal-syntax.ts`.

## Numbers, money and dates

- **Formatting follows the language**: `£1,204.33` in English,
  `1.204,33 £` in Vietnamese; `Friday, 25 September` / `Thứ Sáu, 25 tháng 9`.
  Everything goes through `lib/money.ts` and `lib/dates.ts`; nothing calls
  `toLocaleString` with the browser default.
- **Typing amounts accepts both conventions.** `parseMoneyInput` treats the
  last `.` or `,` as the decimal point when 1–2 digits follow it; other
  separators must be thousands groups. `12,50` and `12.50` are both 12.5,
  and `1.204,33` is 1204.33. Without this, a Vietnamese user typing `12,50`
  would have logged £1,250.
- Currency names come from `Intl.DisplayNames` (`currencyName()`), so the
  currencies screen reads "Đồng Việt Nam" in Vietnamese with no dictionary.
- Amount fields show the language's decimal separator (placeholders, edit
  values, the quick-log keypad's decimal key).

## Data that has a language

| Data | Stored as | Shown as |
| ---- | --------- | -------- |
| Seeded categories | English name + `metadata.key` (`"groceries"`) | `finance.categories.<key>` via `useCategoryName()`; categories you create show their name as typed |
| Journal emotions | English key (`"anxious"`) | `journal.emotions.<key>` via `emotionName()` |
| Journal commands | Nothing stored: syntax only | `/action` `/feeling` `/event`, or `/làm` `/cảm` `/sựkiện` |
| Habit level titles | The API sends English `levelTitle` | Translated on the client by level number (`lib/levels.ts`) |

**The parsers understand both languages at once**, whatever the UI
language:

- Quick log: seeded categories carry Vietnamese aliases (`cà phê`, `ăn trưa`,
  `đi chợ`, `xăng`…), and the translated category name matches too.
  Accents are optional and `đ` matches `d`, so `di cho 250` works.
- Journal: `/cảm lo âu 4/5` is saved as `emotion: "anxious"`; multi-word
  emotions ("tràn đầy năng lượng") match longest-first. Editing an entry
  writes it back in the current language, and it parses either way.

## Not translated

- **User data** (habit names, account names, notes) is shown as typed.
- **Error messages from the API** (e.g. a validation failure) are English.
  The forms validate first, in the user's language, so these are rare.
- `/log?category=` deep links match English or Vietnamese category names.
